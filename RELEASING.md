# Releasing

CampusWeave is not currently licensed for redistribution. Before publishing a
release:

1. Add an approved license and any required third-party attribution.
2. Run the complete repository gate from [README.md](README.md).
3. Verify that checked-in machine artifacts remain fail-closed and that the
   public tree contains no credentials, customer data, or target evidence.
4. Verify CI on the exact release commit.
5. Obtain owner approval for the commit, version, tag, and release contents.

Local checks do not prove publication, live Relution compatibility, or the
outcome of a remote workflow.
