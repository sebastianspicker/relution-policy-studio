# Security policy

This repository follows the policy in [apps/policy-engine/SECURITY.md](apps/policy-engine/SECURITY.md) for every application in it, including the workbench and the planner ([apps/planner/SECURITY.md](apps/planner/SECURITY.md) adds the planner's security boundaries).

Do not disclose a suspected vulnerability in a public issue. Use private vulnerability reporting from the repository's Security tab when it is available; otherwise follow the fallback in the policy-engine policy.
