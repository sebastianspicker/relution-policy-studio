# Support

## Usage questions

Use a GitHub issue for non-sensitive questions about:

- the local CampusWeave interface;
- the offline profile and plan runtime;
- the checked-in Reference University profile;
- OpenAPI catalog rendering and validation; or
- repository tests and documentation.

Include the Python and Node.js versions, operating system, exact non-sensitive
error, command used, and a minimal reproduction based on the checked-in profile
or synthetic fixtures.

Do not attach credentials, customer OpenAPI documents, tenant URLs or
identifiers, device or user data, request or response captures, audit exports,
or live configuration screenshots.

## Security issues

Follow [`SECURITY.md`](SECURITY.md). Do not publish exploit details in a support
issue.

## Out of scope

Project support does not include operating a live tenant, interpreting customer
policy, authorizing MDM changes, or recovering a managed device from a failed
operation.
