# Support

Use a GitHub issue for non-sensitive questions about the local workbench, offline
profile planning, OpenAPI catalog tooling, tests, or documentation. Include the
command, runtime versions, sanitized error, and a minimal reproduction using
checked-in synthetic artifacts.

Do not attach credentials, target URLs or IDs, OpenAPI exports, inventories,
requests, responses, audit data, or screenshots from a live environment. Follow
[SECURITY.md](SECURITY.md) for vulnerability reports.
