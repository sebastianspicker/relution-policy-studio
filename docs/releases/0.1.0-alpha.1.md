# CampusWeave `0.1.0-alpha.1`

Status: proposed GitHub pre-release. Not published.

## Summary

This source alpha provides a loopback-only browser interface and command-line
runtime for validating the Reference University profile and compiling a
deterministic 48-step offline plan. It also provides exact-contract catalog
generation and machine-readable safety documentation for separately authorized
Relution API work.

## Included

- Guided review of organization units, group blueprints, policy intents,
  assignment intents, readiness gates, and exports.
- Institution code and label rebinding with shared profile and plan validation.
- Canonical profile, offline plan, and zero-network dry-run exports.
- Swagger 2.0 and OpenAPI 3.0 through 3.2 catalog rendering into ignored local
  output paths.
- Schemas, registries, templates, validators, and a bounded token transport
  helper for separately authorized API operations.
- Python and Node.js tests, synthetic screenshots, and GitHub community files.

## Known limitations

- Source checkout only. No package, installer, container, or executable bundle
  is provided.
- No live executor, target inventory collector, approval service, or rollback
  executor is included.
- The active editor changes only institution code and label.
- Live tenant compatibility and remote GitHub Actions have not been verified.
- A Chromium-based browser is required to regenerate screenshots.
- No public license has been selected. Publication remains blocked until a
  license and any required attribution are added.

## Upgrade and migration notes

There is no earlier published release and no supported migration path. Future
alpha releases may change profile, plan, schema, and command-line contracts.

Review `RELEASE_STATUS.md` before approving any commit, tag, or publication.
